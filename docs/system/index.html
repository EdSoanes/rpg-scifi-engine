System 00 · Core mechanics

Core mechanics

The dice, time and tempo rules every other part of the cyberpunk system is built on. Twelve documents, one concern each.

The system in five lines

  • Cyberpunk and near-future sci-fi, in the Shadowrun and Eclipse Phase tradition. Moment-to-moment action in detail.
  • Gear heavy, with modest character progression. A career is defined as much by what it carries as by what it knows.
  • Every career path is as satisfying to play as a combat character. The decker, the medic and the face each get scenes where they are the fast one.
  • Built on the engine: the sheet runs the rules. Nobody at the table needs to know any of what follows.
  • Working title only. The system is unnamed; System in these documents is a placeholder, not a name.
One sentence

One roll, 2d10 + rating against a difficulty, where time buys certainty instead of bonuses, and Tempo and Focus are how much time a character gets per turn.

The six ideas

What each document settles
IdeaRule in one line
CertaintyIf the worst possible roll would succeed, there is no roll. If the best possible roll would fail, there is no roll. Dice only in the band between.
MarginHow far a roll clears or misses the difficulty is the effect. Every career has a quantity that scales with it.
PaceSpending more time swaps the dice for a narrower expression with the same middle. Time buys reliability, never brilliance.
Tempo and FocusTwo per-turn pools, body and mind. Actions cost points; pace multiplies the cost. More points, more actions.
GearGear gates what can be attempted and sets how big the effect is. Skill decides whether. Few items add to the roll.
SignatureEverything emits on five channels. Detection is a task roll; signature on the channel moves the difficulty. One mechanic for the street and the matrix.

Still open

  • The name of the system.
  • Exact Tempo and Focus costs for movement, reloading and other non-roll actions.
  • The size of the interval events outside turn tracking. Hour and day are assumed.
  • Whether restricted points (usable only for one kind of action) are worth their complexity. Assumed yes, pending play.
  • Final skill list, careers, and how specialisations are named. The groups are set; the list is a first pass.
Why the mechanics come before the skill list

Every skill, item and career will be expressed through the roll, the pace ladder and the two pools. Settling those first means the content can be written once, against rules that will not shift under it.

House rules for these docs

  • One concern per document. Changing how gear works should not mean touching the roll.
  • Decisions are bullets and tables. Prose only where a rule needs a sentence.
  • Rationale sits in grey notes beside the decision it explains. Skippable on a re-read.
  • Open questions sit in amber notes. Do not assume an answer to one.
  • No cross-referencing. Use the strip at the top. If two docs keep pointing at each other, move the content.
  • Numbers are computed, not guessed. Every probability here comes from the full distribution of the expression. If a number changes, recompute the table.
  • Shared stylesheet in _style.css. Change it once, all thirteen follow.
